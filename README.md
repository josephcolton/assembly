# Introduction to x86-64 Assembly

This repository contains the assembly language source code that I develop when making x66-64 Assembly videos on YouTube.  The videos talking about these programs are available using the following playlist:

[YouTube Playlist](https://www.youtube.com/playlist?list=PLIWqn0hEvlS_11SRbAV8rYOInW9dR9DMQ)

# Coding Environment

The assembly program examples are written for the nasm assembler.  I use the GNU Debugger (gdb) for looking at code.  All of this takes place in Oracle VirtualBox virtual machines with Ubuntu Desktop.
